# Sharing is per-person; GitHub Pages is rejected

Reports quote colleagues by name, so every sharing channel must have real
access control: a read-only collaborator on the private data repo (reads
the Markdown report rendered by GitHub; sees the whole ledger — stated
before granting), a private Claude artifact shared person by person, or
the self-contained HTML file sent directly. GitHub Pages was built and
then removed: Pages sites are readable by anyone with the URL on every
plan except GitHub Enterprise Cloud, and even there access control gates
on repo read access — which for reports living in the ledger repo would
expose the entire ledger. Don't re-propose Pages; obscure URLs are not
access control.
